**What's in place**
- `backend/requirements.txt`: Flask, Flask-SQLAlchemy, Flask-Migrate, and `psycopg[binary]` (the Postgres driver).
- `backend/config.py`: reads `DATABASE_URL` and defaults to `postgresql+psycopg://tidepool:tidepool@localhost:5432/tidepool`.
- `backend/models.py`: `Project` and `Task` tables.
- `backend/app.py`: an app factory with these routes:
  - `GET /health`
  - `GET /api/projects` and `POST /api/projects`
  - `GET /api/projects/<id>/tasks` and `POST /api/projects/<id>/tasks`
- `backend/.env.example`: the connection string to copy into `.env`.
- `docker-compose.yml`: a local Postgres 17 container with the same credentials as the default URL.

**To run it** (needs Docker, or any Postgres you point `DATABASE_URL` at):
```bash
docker compose up -d
cd backend && python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements.txt
flask --app app db init && flask --app app db migrate -m "initial" && flask --app app db upgrade
python app.py
```
