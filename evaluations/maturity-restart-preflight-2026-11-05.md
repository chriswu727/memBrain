# Native restart preflight — 2026-11-05

Candidate `73ee62ee5796902249ddd20b08ed7e4ad6922b3f` checks the selected native engine before stopping a working desktop service. Previously `desktop.restart` checked the live database schema, stopped the API/database, and only then discovered an unavailable target engine during startup. A missing loader dependency could therefore interrupt an otherwise working installation.

For an unadopted profile, preflight prepares and verifies the new bundle without creating a source handoff or changing the profile. For a recorded native transition or source handoff, it validates that binding and executes the selected prefix's tool-version checks. It does not replace the recorded engine with a newly selected supplier. Loader, integrity and disk-space failures propagate before shutdown; Docker restarts retain their existing behavior. The profile is reloaded inside the lifecycle lock.
