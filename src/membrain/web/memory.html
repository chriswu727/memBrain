        actually uses them. You do not need to maintain notes by hand.

Your memory as a brain

        
Each dot is one memory, placed in the area for its kind. Lines are links that memory
          records, such as a note and the message it came from. The layout is illustrative: dot size is not memory
          strength. The brightest dots are the newest.

      

      
    

    
Demo: fictional memories, not anyone's data.

Notes

        
Lasting facts your agent keeps about you. Every session starts with these. Correct anything
          that is wrong; your corrections take precedence over the agent's notes.

      

    

    

      Add a note
      

    

    

  


  

    
Plans and dates
Open plans, upcoming dates and promises. A plan stays open until you confirm it is done.

    
    

  

  

    
People
People your agent remembers, with their names and aliases.

    

  

  

    

      

        
Feelings

        
Feelings you expressed, each kept with the note it belongs to and the message it came from.
          Each one says whether you said it or your agent inferred it. There is no overall score of how you feel.
          Correcting or deleting the note or its message deletes the feeling too.

      

    

    

    

    

      
Clear feelings

      
Deletes every recorded feeling, said or inferred. Notes and messages stay. Feelings are never
        recreated from messages before this point.

      
    

  

  

    

      

        
Conversations

        
Original messages, as recorded. Linked notes show the original messages they refer to.

      

    

    

  


  

    
Search
The same recall your agent uses before replying.

    

      
      
      
    

    

  


  

    
Privacy
Memory is stored on this computer. Recalled text is sent to the agent you use; configured model providers may also process it.

    

      
Recording

      

      

        
        
        
      

      
While paused nothing new is stored; recall of earlier memory keeps working. Text inside
        <private>…</private> and values that look like passwords or keys are never stored.

    

    

      
Export

      
Download everything, with original text and sources, as one JSON file.

      
    

    

      
Erase everything

      
Deletes the content of every message and note. Erasure is recorded, so it also holds if an
        older backup is restored. This cannot be undone.
